## 🔨 Build Instructions

Follow these steps to build the Android application locally.

### Prerequisites
- Android Studio
- JDK compatible with the project's Gradle configuration
- Android SDK

### Build Using Terminal

1. Clone or download this repository.
2. Open the project in Android Studio.
3. Wait for Gradle Sync to complete.
4. Open the terminal in the project root directory.
5. Run the following command:

## 🎨 Compose Preview Details

Jetpack Compose Preview allows developers to preview UI components directly in Android Studio without running the application on a device or emulator.

### Features
- Preview UI components during development.
- Check layout appearance and spacing.
- Test different UI configurations supported by the project.

### How to View Preview
1. Open the Kotlin file containing the composable function.
2. Locate the `@Preview` annotation.
3. Open the Preview panel in Android Studio.
4. Click **Build & Refresh** to render the preview.

**Note:** Compose Preview is available only for components implemented using Jetpack Compose.
